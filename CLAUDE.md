# Superpowers Fork

This repo is a fork of [obra/superpowers](https://github.com/obra/superpowers), customized for enterprise development processes. The base workflow (brainstorming → plans → TDD implementation → review) is intact; the changes are scoped to how specs, review, and execution are structured. See [README.md](README.md) → *Changes from Original Superpowers* for the full list.

## Rule: mirror skill changes in README.md

Any change to an original skill's behavior must be logged in `README.md` under **"Changes from Original Superpowers"** — one section per change, describing what changed plus a one-line rationale. This is a hard requirement before committing skill modifications.
